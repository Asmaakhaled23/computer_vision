# K-Means Clustering on Virtual Data Points

## Project Overview
This project implements the K-Means Clustering algorithm on virtual data points using Python.

## Technologies Used
- Python
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Implementation Steps
1. Import Libraries
2. Generate Virtual Data Points
3. Visualize Original Data
4. Apply K-Means Clustering
5. Visualize Clusters and Centroids
6. Display Results

## Results
The algorithm successfully grouped 150 virtual points into 3 clusters and calculated their centroids.

## Execution
Implemented using Google Colab.
